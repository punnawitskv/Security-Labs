# Security Lab Writeups

This repository contains written walkthroughs and notes for security labs completed by the author.

The repository is divided into two main lab categories:

- `ccmt/`: internship labs completed during training with the Royal Thai Army.
- `thm/`: TryHackMe labs completed as personal practice.

## Repository Structure

- `ccmt/`
  - Contains lab folders such as `lab01/`, `lab02/`, ..., and `pt01/`.
  - Each lab folder includes a `writeup.md` file and, when available, an `images/` folder supporting the writeup.
  - Some labs also include additional notes in `note.txt`.

- `thm/`
  - Contains TryHackMe writeups in markdown files such as `AS02-Writeup.md`, `AS03-Writeup.md`, `AS04-Writeup.md`, and `AS06-Writeup.md`.

## How to Use This Repository

1. Browse the `ccmt/` folder to review the internship lab writeups.
2. Browse the `thm/` folder to review TryHackMe challenge reports.
3. Open the `writeup.md` or `*-Writeup.md` files for each lab to read the full walkthrough.

## Notes

- The `ccmt` labs reflect practical experience gained during a training internship with the Royal Thai Army.
- The `thm` labs are based on TryHackMe challenge practice and learning.
